# Portfolio de Díaz

Portfolio personal estático creado a partir del README público de GitHub de `diaz827`.

## Archivos

- `index.html` — estructura y contenido.
- `styles.css` — diseño responsive, animaciones y componentes visuales.
- `script.js` — menú móvil, scroll reveal y año automático.
- `juego.html` — minijuego interactivo integrado.

## Cómo verlo

Abre `index.html` directamente en el navegador.

## Publicarlo con GitHub Pages

1. Crea un repositorio.
2. Sube los archivos.
3. En GitHub ve a **Settings → Pages**.
4. Selecciona `Deploy from a branch`, rama `main` y carpeta `/root`.
5. Guarda y espera a que GitHub Pages publique el sitio.
