# Portfolio de Díaz

Portfolio personal de **Daniel Díaz Canosa** — estudiante de Desarrollo de Aplicaciones Web (DAW). Sitio estático hecho con HTML, CSS y JavaScript vanilla, sin frameworks ni build.

**En vivo:** https://soydiaz.pages.dev/

## Características

- **100% responsive** (móvil, tablet y escritorio)
- **HTML5 semántico + accesibilidad** (landmarks, `aria`, foco visible, `prefers-reduced-motion`)
- **i18n en 3 idiomas**: español, inglés y portugués (guardado en `localStorage`)
- **Tema oscuro/claro** con persistencia
- **Filtros de proyectos** (Todos / Web / Java)
- **Secciones**: hero, proyectos, stack, educación, experiencia, certificaciones y contacto con formulario
- **Minijuego** Flappy Bird integrado (`pages/juego.html`)
- **Formulario de contacto** con [Formsubmit](https://formsubmit.co) (sin backend propio)

## Estructura

```
portfolio-diaz/
├── index.html          # Estructura y contenido de la portada
├── stiles/
│   └── styles.css      # Diseño responsive, animaciones y componentes
├── script/
│   └── script.js       # Menú móvil, scroll reveal, i18n, tema y filtros
├── pages/
│   └── juego.html      # Minijuego autónomo (CSS y JS inline, sin styles.css ni script.js)
├── img/                # Fotos, imágenes de proyectos y favicon
├── archivos/           # PDFs: currículum y certificados
├── robots.txt
├── sitemap.xml
└── README.md
```

## Cómo verlo en local

No hay dependencias ni build: abre `index.html` directamente en el navegador.

## Despliegue

Desplegado en **Cloudflare Pages** a partir de la rama `main` del repositorio: https://soydiaz.pages.dev/
